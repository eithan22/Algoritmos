# Algoritmos — C# Exercises 🧠

A collection of **C# algorithm and data structure exercises** written in .NET 8. This repository documents solutions to programming challenges and fundamental programming concepts implemented in C#.

---

## 📋 Description

This repository contains exercises practiced during the Software Development program at ITLA. Each exercise focuses on a specific algorithm, pattern, or programming concept, serving as both a learning journal and a demonstration of C# problem-solving skills.
